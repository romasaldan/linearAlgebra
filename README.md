# Linear Algebra Engine (Legacy — 2018)

A custom-built JavaScript library for matrix operations and linear algebra calculations.

## 📌 Motivation
This project was created during my university years to automate matrix-related assignments. The goal was to build a tool that could handle complex algebraic operations that are tedious to perform manually.

### Key Capabilities:
* **Matrix Multiplication:** Efficient row-by-column calculation.
* **Determinant Calculation:** Recursive implementation for square matrices.
* **Inverse Matrix:** Finding the inverse using the adjugate matrix method.
* **Matrix Transformations:** Transposition and basic arithmetic.

### Historical Context:
* **Level:** Pre-junior / Student project.
* **Tech:** ES5 JavaScript.
* **Focus:** Algorithmic logic and mathematical accuracy.
